# Difficulty is graded by solving technique, not given count

A puzzle's difficulty is the tier of the hardest named logical technique required to solve it without guessing (naked/hidden singles → locked candidates → pairs/triples → X-Wing), not the number of Givens. Players judge difficulty by *what they have to do*, and two puzzles with the same given count can differ wildly — a sparse puzzle solvable by singles alone feels easier than a denser one that forces X-Wing. The cost is a logical solver that grades each generated puzzle, but it is the only way the difficulty labels stay honest.

_Considered: grading by given count — simpler, but produces mislabeled puzzles and erodes trust in the labels._
