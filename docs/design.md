# 数独游戏 · 详细设计

> 形态：单文件网页（`index.html`，内联 CSS/JS，零依赖，双击即开，可直接挂 GitHub Pages）
> 语言/规则见 `CONTEXT.md`；不可逆决策见 `docs/adr/0001`、`docs/adr/0002`。

## 1. 目标与边界

**做**
- 单机完整版：浏览器内生成谜题 + 完整玩家交互（候选数、撤销/重做、计时、提示、难度切换、存档、最佳成绩）。
- 唯一解；难度按**逻辑技巧层级**分级。
- 响应式双端；明暗跟随系统。

**不做**
- 多人、联网、排行榜、账号体系。
- 超过 X-Wing 的高阶技巧（XY-Wing / Swordfish / 链）——超出即判该题不可用（重新生成）。
- 服务端、构建链、第三方库。

## 2. 分层架构

单文件内按职责切分成 6 个区块（`<script>` 内等价的命名空间对象）：

```
┌─────────────────────────────────────────────┐
│  UILayer   渲染棋盘/数字盘/统计卡，绑定事件      │
├─────────────────────────────────────────────┤
│  Controller 键鼠输入 → 游戏动作 → 状态变更       │
├─────────────────────────────────────────────┤
│  GameState  值/候选/选中/计时/历史/暂停          │
├─────────────────────────────────────────────┤
│  HintEngine 在当前玩家状态上跑一步逻辑，产出解释   │
├─────────────────────────────────────────────┤
│  Grader     逻辑求解器 + 技巧分级                │
├─────────────────────────────────────────────┤
│  Generator  填满 → 对合挖洞 → 唯一解校验         │
├─────────────────────────────────────────────┤
│  Grid       索引/peers/units/位掩码 工具         │
└─────────────────────────────────────────────┘
```

依赖方向自上而下，`Grid` 无状态、纯函数，可独立测试。

## 3. 数据模型

### 3.1 棋盘索引与预计算（Grid）
- 81 个 Cell，索引 `i = r*9 + c`；`b = (r/3|0)*3 + (c/3|0)`。
- `PEERS[i]`：20 个同行/列/宫邻居（去自身）。
- `UNITS`：27 个单元（9 行 + 9 列 + 9 宫），每个 9 个索引。
- `BOX_OF[i]`、`ROW_OF[i]`、`COL_OF[i]`。
- 位掩码：数字 d 对应 `1<<(d-1)`；9 位 mask 表示候选集。

### 3.2 谜题与对局状态
```js
Puzzle = {
  givens:   Int8Array(81),   // 0 = 空, 1..9
  solution: Int8Array(81),   // 完整解
  difficulty: 'easy'|'medium'|'hard'|'expert',
  givensCount: number,
}

Game = {
  puzzle: Puzzle,
  values: Int8Array(81),          // 玩家当前填入
  notes:  Uint16Array(81),        // 每格候选位掩码
  givenMask: Uint8Array(81),      // 1 = 不可改
  selected: {r,c} | null,
  mode: 'digit' | 'note',         // 填数 / 记候选
  time: seconds, paused: bool,
  hintsUsed: number, undosUsed: number,
  history: Action[], future: Action[],
  status: 'playing'|'won'|'paused',
}

Action = { type:'set'|'note'|'erase', i, prevValue, prevNote, nextValue, nextNote }
```
- `notes` 用 16 位足够（9 位有效）。自动候选开启时由 `values` 反推，不落库。
- 撤销栈存**增量 Action**（不是整盘快照），内存小、重放快。

## 4. 算法

### 4.1 完整盘生成
随机化回溯：
1. 每格按洗牌后的候选顺序试填；
2. 用 `rowMask/colMask/boxMask` 做 O(1) 合法性判断；
3. 填满 81 格即得完整解。
> 9×9 规模下通常 < 5ms。不需要 MRV；若出现极端慢，追加 MRV 启发式。

### 4.2 对合挖洞 + 唯一解
```
cells = shuffle([0..80])
for i in cells:
    j = 80 - i                       // 180° 对合
    if both empty: continue
    remove(i); remove(j)
    if countSolutions(givens, limit=2) > 1:
        restore(i); restore(j)       // 破坏唯一性 → 还原
    if givensCount <= targetGivens: break
```
- `countSolutions` 回溯计数，**数到 2 即停**（只关心唯一性），位掩码剪枝。
- 以 `targetGivens` 为目标上限（越少越难），实际数量受唯一性约束。

### 4.3 逻辑求解器 + 技巧分级（Grader）
维护每格候选 mask 与单元占位。**按难度从低到高依次尝试**，某技巧能推进就应用并记录层级，直到解开或卡死。

| 层 | 技巧 | 说明 |
|---|---|---|
| T1 | Naked single 唯一候选 | 格候选只剩 1 个 |
| T2 | Hidden single 隐藏单 | 单元内数字只剩一个可放格 |
| T3 | Locked candidates 区块指向/声明 | 区块内某数只在同一行/列 |
| T4 | Naked/Hidden pair·triple 数对/三数组 | 单元内组合约束 |
| T5 | X-Wing | 两行两列对角配对消除 |

**分级规则**：始终优先应用最低层可用技巧；最终 `grade = 用到的最高层`。
- 未用到 T3 及以上 → **简单**（仅 T1/T2）
- 最高到 T3 → **中等**
- 最高到 T4 → **困难**
- 用到 T5 → **专家**
- 卡死（无技巧可推进）→ 超出能力，**弃题重生成**。

> 这套"最低优先 + 记录最高层"保证：某层被用到，说明更低层当时已失效，故该层是**必需**的，难度标签诚实。

### 4.4 难度命中
生成 → 挖到目标 given 数 → 分级。
- 若 `grade` 与目标档不符：最多重试 N 次（N≈8）；仍未命中则取**最接近档位**并标记（或降档），保证总能开局。
- 生成总预算 ~200ms；超预算降级重试。

### 4.5 提示（Hint）
对**玩家当前状态**运行逻辑求解器一步：
1. 若存在 Conflict → 提示"先解决冲突格"，并高亮。
2. 否则推导当前候选，找最低层可推进的技巧。
3. 产出 `{technique, tier, cells[], digit, text}`；UI 高亮相关格/数字并显示一句话解释，如：
   `R3C5 是该宫唯一能放 7 的格（隐藏单）`。
4. 不直接填值——玩家仍需自己落子。

## 5. 交互与状态机

### 5.1 动作
- 选中格（点击 / 方向键）
- 填数 `1-9`（数字盘 / 键盘）
- 擦除（Backspace / 数字盘橡皮）
- 切换笔记模式 `N` / 按钮
- 撤销 `Ctrl/⌘+Z`、重做 `Ctrl/⌘+Shift+Z`
- 提示 `H` / 按钮
- 暂停 `P` / 按钮（遮罩盘面）
- 新局 / 换难度

### 5.2 填数规则
- Given 格不可改（点击仅选中，不回写）。
- 填数后：清除该格候选；自动从同 peer 的候选里移除该数字；冲突检测并标红（不阻断）。
- 胜利判定：81 格填满且无 Conflict（唯一解下即正确）。
- 提示/撤销计数用于统计卡。

### 5.3 撤销语义
- 每个 Action 入 `history`，清空 `future`。
- 撤销把 Action 反向应用并压入 `future`；重做反之。
- 提示不产生历史；计时不随撤销回退。

## 6. 视觉与布局

### 6.1 布局
```
┌──────── 顶部：难度选择 · 计时/暂停 · 新局 ────────┐
│                                                   │
│               9×9 棋盘（等比居中）                  │
│                                                   │
├──── 数字盘 1–9 + 橡皮（可用数字高亮/用完置灰）────┤
├──── 提示 · 撤销 · 重做 · 笔记模式 ─────────────────┤
│         完成统计卡（胜利时覆盖弹出）                 │
└───────────────────────────────────────────────────┘
```

### 6.2 视觉
- 单强调色（如靛蓝 `#5b6cff` 系）；灰阶承载盘面。
- `:root` CSS 变量 + `@media (prefers-color-scheme)` 切明暗；`color-scheme` 同步。
- 细线分隔；每 3 格加粗宫线（`box-shadow` 或 `border` 方案）。
- 状态样式：选中格、同行/列/宫淡底、同数字高亮、冲突红、Given 深色、用户填入强调色。
- 动效克制：填数淡入、完成轻微高亮脉冲，均 `prefers-reduced-motion` 可关。

### 6.3 响应式
- 棋盘 `width: min(92vw, 92vh - 200px, 560px)`，`aspect-ratio: 1`。
- 触控热区 ≥ 44px；数字盘换行布局。
- `viewport` 设 `user-scalable=no` 防双击缩放误触（可选）。

## 7. 持久化（localStorage）

| Key | 内容 |
|---|---|
| `sudoku:save` | 进行中对局快照（puzzle、values、notes、time、counters、difficulty） |
| `sudoku:best` | `{easy,medium,hard,expert}` → 秒数 |

- 载入时若有存档 → 询问"继续上一局 / 开新局"。
- 每次动作节流写盘（~500ms）。
- localStorage 不可用 → 静默降级，不阻塞游戏。

## 8. 文件结构

交付：单个 `index.html`
```
index.html
├── <style>  变量/布局/棋盘/数字盘/响应式/动效
├── <body>   顶部栏 / 棋盘 / 数字盘 / 工具栏 / 统计卡
└── <script>
    - Grid（索引/peers/units/mask）
    - Solver（solve / countSolutions）
    - Generator（fillGrid / carve / grade 命中）
    - Grader（技巧层 T1–T5）
    - HintEngine
    - GameState（values/notes/history/persistence）
    - Controller（键鼠绑定）
    - UI（render / 高亮 / 统计卡）
    - bootstrap()
```
开发期可选 `src/*.js` 分文件 + 一个 3 行的拼接脚本；最终仍产出单文件。**默认直接写单文件**（零依赖、无工具链）。

## 9. 性能与边界

- 规模固定 9×9：生成/求解全同步，毫秒级；新局时展示"生成中…"骨架防白屏。
- 生成失败/超预算：降档重试，绝不让开局卡死。
- 暂停：冻结计时 + 遮罩 + 拦截输入。
- 刷新恢复：保持 paused 语义，恢复后继续计时。
- 移动端：数字盘替代软键盘；避免键盘弹出遮挡。
- 可访问性：格为可聚焦按钮，`aria-label` 描述行列/值；键盘可达。

## 10. 里程碑（实现顺序）

1. **Grid + Solver**：索引/peers/units、`solve`、`countSolutions`（控制台自测）。
2. **Generator**：填满 → 对合挖洞 → 唯一解；输出合法盘。
3. **Grader**：T1–T5 + 分级；生成按档命中。
4. **UI 骨架**：棋盘渲染 + 键鼠输入 + 冲突/辅助高亮。
5. **候选数**：笔记模式 + 自动清理 + 自动候选开关。
6. **历史与时间**：撤销/重做、计时/暂停、最佳、存档。
7. **提示**：一步逻辑 + 高亮 + 文案。
8. **打磨**：主题/响应式/完成统计卡/动效/可访问性。
9. **自测**：每档难度的唯一解与可解性、撤销链、刷新恢复、移动端。

## 11. 自测清单（关键用例）

- [ ] 每档生成 50 局：`countSolutions == 1` 且 Grader 能解出、档位匹配。
- [ ] 任意难度存在至少一局可玩（不因命中失败卡住）。
- [ ] 填错 → 冲突即时标红；改正后红消失。
- [ ] Given 格不可编辑。
- [ ] 撤销/重做链正确，重做分支在新建动作后清空。
- [ ] 刷新后 continue 恢复值/候选/用时；best 按难度更新。
- [ ] 暂停时输入被拦截、计时冻结、盘面遮挡。
- [ ] 手机竖屏棋盘不溢出、数字盘可点、热区达标。
- [ ] 明暗模式跟随系统，无低对比文本。
